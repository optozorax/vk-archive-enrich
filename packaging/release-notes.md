## Как запустить на Windows (без Python и прочего)

1. Скачайте **vk_archive_enrich-windows-x64.zip** ниже, в разделе Assets, и распакуйте.
2. Откройте папку `vk_archive_enrich` и запустите **vk_archive_enrich.exe**.
   Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», а затем «Выполнить в любом случае».
   Предупреждение появляется потому, что у программы нет платной цифровой подписи.
3. В окне выберите папку распакованного архива VK, отметьте, что скачать, и нажмите «Начать».

Чтобы программа могла скачивать, войдите в vk.ru в Firefox. Chrome и Edge не дают программам читать свои
cookies. Для них есть вход через файл cookies.txt или через токен: в окне есть кнопка «Как получить?».

Внутри уже есть всё нужное: Python, ffmpeg (для музыки) и yt-dlp. Устанавливать ничего не нужно.
Можно запускать и из командной строки: `vk_archive_enrich_cli.exe --help`.

Подробности: [README](https://github.com/optozorax/vk-archive-enrich#readme).
